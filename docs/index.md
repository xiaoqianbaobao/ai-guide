# 欢迎来到 AI Agent Guide

`AI Agent Guide` 是一个面向开发者的中文知识站点，关注从 LLM 原理到 Agent 工程实践的完整知识链路。

这里不会只罗列工具和框架，而是试图回答更关键的问题：

- 模型到底是什么
- 上下文为什么决定系统表现
- Agent 为什么本质上是一个系统而不只是一个模型
- Memory、多 Agent、评估为什么会成为真正的工程主题

## 阅读入口

- [学习指南](/guide/)：先看整体学习路径和使用方式
- [序章](/00-preface/)：先建立 AI 原生开发的整体认知
- [语言模型基础](/01-llm-foundations/)：理解 LLM 和上下文窗口
- [Agent 核心机制](/02-agent-core/)：理解 Tool Use、Context Engineering 和 Agent 闭环
- [先修基础](/models/python-basics/)：如果编程基础还不稳，先补 Python

