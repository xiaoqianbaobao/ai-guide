# 序章：范式转移

这一模块不是背景介绍，而是整套知识体系的起点。

## 模块定位

这个模块解决的不是某个单点技术问题，而是三个更基础的问题：

- 为什么 AI Agent 不是“再学一个框架”那么简单
- 为什么很多人学了很多工具，依然搭不出稳定系统
- 怎样建立一条能长期扩展的学习主线

## 适合谁先读

- 第一次系统接触 AI Agent，希望先看清全局的人
- 已经用过一些 AI 工具，但知识仍然零散的人
- 想把后面的模型、Agent、Memory 串成一条主线的人

## 这个模块讲什么

- 为什么今天的开发工作会被称为一次新的范式转移
- AI 原生开发者和传统开发者的认知差异
- 如何使用这套知识体系建立自己的学习主线

## 学完你会掌握

- 用更稳定的视角理解 AI Agent 的整体问题域
- 看清知识地图和各模块之间的关系
- 找到适合自己的起步顺序

## 进入后续模块前你应该得到什么

- 知道整套站点为什么从“序章”开始，而不是先讲某个热门工具
- 能区分“知识主线”和“工具清单”这两种完全不同的学习方式
- 对后续为什么先讲 LLM、再讲 Agent、再讲 Memory 有清晰预期
