## 三条推荐路径

### 路径 A：已经在用 AI 工具，但缺少底层理解

先读序章，再进入语言模型基础和 Agent 核心机制。

### 路径 B：希望系统学习 AI Agent 工程

按 序章 -> 语言模型基础 -> Agent 核心机制 -> Memory -> 多 Agent -> 工具与框架 -> 评估与进化 的顺序推进。

### 路径 C：编程基础还不稳

先补齐基础编程、文件处理和脚本能力，再回到主线模块。

## 每篇文章应该怎么读

先看知识地图，再看文章头部信息，再进入核心概念与实践，最后回到模块页确认下一步。
