# 线性代数第一课：从向量、点积到检索与注意力

为什么知识库可以按“语义相近”找到资料？Transformer 为什么要计算 Q 和 K 的乘积？这两个问题背后都用到向量和点积，但它们的含义并不完全相同。

本课先用二维小例子建立直觉，再运行没有第三方依赖的 Python。示例中的数字是为了手算而构造的，**不是实际文本的 embedding，也不代表真实检索质量**。建议先掌握列表、函数和循环；完成后可以继续阅读 [Self-Attention 与 QKV](../01-llm-foundations/chapter-03-self-attention-qkv)。

## 1. 向量：一组有顺序的数字

向量可以写成 $x=[2,1]$。几何上，它可以表示从原点指向坐标 $(2,1)$ 的箭头；计算时，也可以把它看成两个有顺序的数。把顺序交换成 $[1,2]$，通常就是另一个向量。

向量长度（范数）可表示为 $\|x\|=\sqrt{2^2+1^2}=\sqrt{5}$。在机器学习中，一个向量可能有几百或几千维；每一维的意义不一定能单独翻译成人类概念。模型产生的 embedding 是一种表示，**不是天然可靠的事实或权限证明**。

在本文里，一个长度为 2 的输入向量称为“二维”。如果系统声称两个向量可以做点积，它们必须处在相容的维度与表示空间中；单纯长度相同并不保证来自不同模型的向量能够比较。

## 2. 点积：方向与长度一起影响结果

两个同维向量的点积是对应位置相乘再求和：

$$
[a_1,a_2]\cdot[b_1,b_2]=a_1b_1+a_2b_2
$$

例如 $[2,1]\cdot[3,4]=2\times3+1\times4=10$。几何上，对非零向量也可以写成 $a\cdot b=\|a\|\|b\|\cos\theta$：方向越接近通常越有利于点积，但长度也会改变结果。

看一组容易误判的数：查询向量 $q=[1,0]$；文档 A 是 $[1,1]$，文档 B 是 $[10,10]$。两者方向相同，但与查询的点积分别是 1 和 10。如果只看点积，B 会排在 A 前面；这并不一定表示 B 的语义更相关，差异完全可能来自向量长度。

### 余弦相似度：把长度因素分开

对于两个非零向量，余弦相似度为：

$$
\cos(a,b)=\frac{a\cdot b}{\|a\|\|b\|}
$$

上例中 A 和 B 与 $q$ 的余弦都是约 0.707。它衡量方向上的关系；**零向量没有定义好的余弦相似度**，因为分母为零。实际向量检索应以所用模型和索引的文档为准：有些模型或索引使用归一化向量、点积、余弦或其他距离，不能一概而论。分数也不是“答案正确的概率”。

## 3. 自己运行并检查边界

在仓库根目录运行：

```bash
cd examples/linear-algebra
python3 basics.py
python3 -m unittest -v
```

你会看到短向量的点积为 1、长向量为 10，而两者余弦均约为 0.707；矩阵例子的输出为 `[4, 10]`。测试也检查维度不一致和零向量。完整代码见 [linear-algebra 示例](https://github.com/xiaoqianbaobao/ai-guide/tree/main/examples/linear-algebra)。

```python
def dot(a, b):
    if not a or len(a) != len(b):
        raise ValueError("vectors must be non-empty and have the same length")
    return sum(x * y for x, y in zip(a, b))
```

为什么要先检查长度？Python 的 `zip` 会在较短的序列结束时停止；直接求和可能悄悄丢掉后面的值，得到一个看似正常、实际错误的分数。生产系统还应检查数值类型、非有限值、索引维度和模型版本；这个简化函数没有覆盖全部情况。

## 4. 矩阵：把一个向量映射到另一个向量

将矩阵 $W$ 乘以列向量 $x$：

$$
\begin{bmatrix}1&2\\3&4\end{bmatrix}
\begin{bmatrix}2\\1\end{bmatrix}
=
\begin{bmatrix}4\\10\end{bmatrix}
$$

第一行与输入做点积得到 $1\times2+2\times1=4$；第二行得到 $3\times2+4\times1=10$。一个形状为 $m\times n$ 的矩阵乘以 $n$ 维列向量，结果是 $m$ 维。维度不是装饰：写代码前先列形状，往往能提前发现拼接和乘法错误。

同一个运算也能从列的角度理解：输出是第一列的 2 倍加第二列的 1 倍。若固定基准坐标，矩阵就是一种线性变换；这里的“线性”意味着保持向量加法和数乘。加上偏置的 $Wx+b$ 则是仿射变换，不应笼统称为严格的线性映射。

## 5. 它们如何连接到 Agent 系统

**检索：** 用户问题和文档片段经兼容的编码模型生成向量，索引根据某种相似度找出候选资料，后续可能再排序。向量分数只能提供候选线索；是否有权限、资料是否过期、引用是否支持结论，都需要额外检查。用[企业助手回归评估](../agent/cases/knowledge-assistant-evaluation)设计“同义表达”和“跨租户不可见”两种不同测试。

**注意力：** 在经典 Transformer 的缩放点积注意力中，输入经过不同的可学习变换得到 Q、K、V，再用 $QK^T/\sqrt{d_k}$ 计算分数，经 softmax 得到对 V 的加权组合。这里的分数不是通用语义检索分数，也不必然是余弦相似度；它的作用范围和训练目标由模型结构决定。详见 [Transformer 论文](https://arxiv.org/abs/1706.03762)与本站 [Self-Attention](../01-llm-foundations/chapter-03-self-attention-qkv)。

**决策边界：** 即使相似度高，文档也可能是旧版本、错误租户的材料，或只与问题表面相似。先做授权过滤，再验证引用和任务效果；不要把数学相似度当作事实正确性的证明。

## 6. 三个动手问题

1. 手算 $[1,2]\cdot[3,-1]$；再用 `dot` 核对。若两个向量正交，点积是什么？
2. 把文档 B 改为 `[100, 100]`，比较点积与余弦。再把查询改为零向量，观察程序为什么拒绝计算。
3. 写一个 $2\times3$ 矩阵和三维向量，先标注输入输出形状、手算，再用 `matvec` 验证；传入错误长度，检查是否明确报错。
