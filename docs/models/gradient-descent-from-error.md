# 优化第一课：用梯度下降让模型从错误中学习

想象你需要预测一个小团队处理任务所需的时间。你先写下一个很简单的模型：任务量为 $x$ 时，预测时间是 $wx+b$。但 $w$ 和 $b$ 应该取什么值？如果预测与已知数据不一致，怎样系统地调整它们？

梯度下降给出一种迭代方法：先定义误差，再计算参数变化对误差的影响，沿着局部下降方向更新。本课使用完全虚构、刻意线性的数据；它不构成对真实工单时长或客户收益的预测。建议先掌握[向量与矩阵](./linear-algebra-for-agents)。

## 1. 从预测到损失

设模型为 $\hat y=wx+b$。给定 $n$ 组样本 $(x_i,y_i)$，一种常见损失是均方误差：

$$
L(w,b)=\frac{1}{n}\sum_{i=1}^{n}(wx_i+b-y_i)^2
$$

先看一条样本 $x=1,y=3$，参数初始为 $w=0,b=0$。预测是 0，误差是 $0-3=-3$，平方损失是 9。平方会让较大的误差受到更高惩罚，但这也意味着异常值可能产生较大影响；不同业务需要选择合适的损失与评价指标。

模型参数是通过训练调整的值；学习率、训练步数和数据划分等是实验设计中的选择。两者都应记录，才能复现结果。

## 2. 梯度指向哪里

对全部训练样本求平均时，损失对两个参数的偏导数分别是：

$$
\frac{\partial L}{\partial w}=\frac{2}{n}\sum_i(wx_i+b-y_i)x_i,\quad
\frac{\partial L}{\partial b}=\frac{2}{n}\sum_i(wx_i+b-y_i)
$$

把偏导数放在一起，就是当前位置的梯度。对于前面的一条样本，两个偏导数都是 -6。若学习率 $\eta=0.1$，同时更新：

$$
w_{new}=w-\eta\frac{\partial L}{\partial w},\quad
b_{new}=b-\eta\frac{\partial L}{\partial b}
$$

新参数为 $w=0.6,b=0.6$，预测从 0 变为 1.2，这条样本的损失从 9 变为 3.24。这里的每一步都能手算；这**不保证**任意数据、任意学习率或任何模型都能在每一步降低损失。

## 3. 跑一遍并核对导数

在仓库根目录执行：

```bash
cd examples/gradient-descent
python3 linear_fit.py
python3 -m unittest -v
```

示例使用四条虚构数据 `(0,1)、(1,3)、(2,5)、(3,7)`。训练前平均损失为 21；在示例设置下，参数会接近 $w=2,b=1$。这组数据正好由一条直线生成，目的是验证实现，不是证明模型在真实业务中有效。[完整源码与测试](https://github.com/xiaoqianbaobao/ai-guide/tree/main/examples/gradient-descent)没有第三方依赖。

核心更新与公式对应：

```python
_, dw, db = loss_and_gradient(xs, ys, w, b)
w -= learning_rate * dw
b -= learning_rate * db
```

测试还用**中心有限差分**近似检查偏导：将一个参数分别增加和减少很小的数，比较损失变化，再与解析梯度核对。数值差分会受到步长和浮点误差影响，因此测试使用容差；它是调试工具，不是自动证明全部训练代码正确。

## 4. 学习率、数据与泛化

学习率过小可能收敛很慢；过大可能在低点两侧震荡甚至发散。不同特征的数值尺度、损失形状和优化器也会影响合适范围。先观察损失曲线与梯度，再调整参数；如果出现 `NaN` 或无穷大，应排查数据与数值稳定性，而不是只增加训练步数。

训练损失降低只说明模型更贴合**训练样本上的目标**。它可能记住噪声、使用了未来信息，或者在实际业务分布改变后失效。应提前划分训练、验证和测试数据；时间序列通常需要考虑按时间切分。报告实际样本、数据来源、指标和不适用场景。

同样，真实任务不一定满足线性关系。增加复杂模型可能提高表达能力，也会改变数据需求、成本与过拟合风险；先与简单基线比较。对 Agent 的评估，应将模型预测误差与[真实任务完成、权限和成本](../06-eval-evolution/production-evaluation-loop)分开测量。

## 5. 与神经网络、CNN 的连接

神经网络可以看成多层带参数的变换与非线性组合；训练仍需要损失、梯度与参数更新。反向传播利用链式法则高效计算各层参数的梯度，实际框架通常提供自动微分。CNN 的卷积核权重也可以通过类似机制学习，但[上一课的纯 Python 互相关](./cnn-from-pixels-to-features)没有实现训练或反向传播。

梯度下降并不是唯一优化方式；实际系统可能采用小批量、动量、Adam 等方法，并结合学习率调度和正则化。先能解释数据、损失、梯度和更新的关系，再学习具体优化器更容易判断它们解决什么问题。

## 6. 练习

1. 手算单样本 $x=2,y=5,w=0,b=0$ 的损失与两个偏导数；再调用 `loss_and_gradient` 核对。
2. 把学习率改为 `0.01` 和 `1.0`，观察损失变化；记录步数和参数，不要预先假设大一点一定更快。
3. 把一条训练样本留作测试，只在剩余样本上拟合，比较训练与留出样本的误差；四条数据不足以评估真实泛化。
4. 用有限差分测试故意写错的梯度，确认测试能够发现它；再解释为什么这仍不代替对整个数据流水线的测试。
