# CNN 第一课：从局部窗口到可学习的视觉特征

如果要识别一张图片里的工单截图、产品标签或设备异常，能否把每个像素全部连接到每个神经元？可以，但这样的连接很快会变得庞大，也没有直接利用图像中相邻像素往往相关的结构。

卷积神经网络（CNN）通过**局部连接与参数共享**处理这类数据。本课先手算一个小窗口，再用纯 Python 运行二维互相关；示例不是训练好的视觉模型，也不会识别真实图片。建议先读 [向量与矩阵基础](./linear-algebra-for-agents)。

## 1. 图像、通道和局部窗口

灰度图片可以用二维数表表示，每个数字代表一个像素值；彩色图片通常还包含多个通道。一个批次的图片常按 `[批次, 通道, 高, 宽]` 表示，例如 `[8, 3, 32, 32]`。不同框架也可能采用其他排列，必须看具体接口。

先考虑教学用的单通道 $3\times3$ 输入和 $2\times2$ 核：

$$
X=\begin{bmatrix}1&2&0\\0&1&2\\2&2&1\end{bmatrix},\quad
K=\begin{bmatrix}1&0\\-1&0\end{bmatrix}
$$

把核放在左上角，对应元素相乘再求和：$1\times1+2\times0+0\times(-1)+1\times0=1$。向右移动一格得到 1；再计算下一行两个窗口，得到 -2 和 -1。最终输出是：

$$
\begin{bmatrix}1&1\\-2&-1\end{bmatrix}
$$

这个核对窗口左侧上下两个值的差异有响应；它只是我们人为设计的例子。真实 CNN 的核通常由数据、损失函数和优化算法训练得到，不保证每个通道都能被简单命名为“边缘”或某个语义概念。

### 为什么代码叫互相关，而课程仍称卷积？

数学中的严格卷积会翻转核；很多深度学习框架中名为 `Conv2d` 的操作实际上使用**互相关**，不先翻转核。两者对本文手算会得到不同数值。学习和调试时应看清框架约定；[PyTorch Conv2d 文档](https://docs.pytorch.org/docs/stable/generated/torch.nn.Conv2d.html)明确说明其运算。

## 2. 运行并验证形状

在仓库根目录执行：

```bash
cd examples/cnn-basics
python3 correlation.py
python3 -m unittest -v
```

预期互相关结果为 `[[1, 1], [-2, -1]]`；经 ReLU 后为 `[[1, 1], [0, 0]]`。3 条测试覆盖手算结果、步长和填充，以及非法形状。源码见 [cnn-basics 示例](https://github.com/xiaoqianbaobao/ai-guide/tree/main/examples/cnn-basics)。

核心运算是将输入窗口和核的对应位置相乘求和：

```python
sum(padded[i * stride + y][j * stride + x] * kernel[y][x]
    for y in range(kh) for x in range(kw))
```

该实现只处理单张、单通道二维数据，不含偏置、反向传播或训练；生产框架会处理批次、通道、硬件加速与数值细节。

## 3. 步长和填充改变什么

**步长** $S$ 决定窗口每次移动几格；**填充** $P$ 可以在输入四周增加像素，本例使用零。对高度为 $H$、核高为 $K$、无空洞卷积（dilation 为 1）的情况，输出高度为：

$$
H_{out}=\left\lfloor\frac{H+2P-K}{S}\right\rfloor+1
$$

宽度同理，取整向下。前面的例子 $H=3,K=2,P=0,S=1$，输出高度为 2；如果加入填充、改变步长，结果的尺寸和边界数值都可能变化。空洞卷积时需要将公式中的核大小替换为有效核大小；不要把本式直接用于所有配置。

### 参数共享与多通道

同一个核在不同位置重复使用，这叫参数共享；它让模型不用为每个位置单独学习一套相同形状的权重。多通道时，一个输出通道的核跨越所有输入通道，对各通道局部结果求和；多个核产生多个输出通道。

例如，无分组卷积、3 个输入通道、16 个输出通道、$3\times3$ 核并为每个输出通道提供偏置，参数量是 $16\times3\times3\times3+16=448$。该数量与输入图像的高宽无关，但计算量和特征图内存仍会受尺寸影响。分组或深度可分离卷积的参数计算不同。

## 4. 从一层到完整网络

常见网络会将多个卷积层与非线性、下采样或池化、归一化以及任务输出层组合。ReLU 逐元素计算 $\max(0,x)$；本例中两个负数被置零。叠加非线性层可以表示更复杂的关系，但只运行本文的互相关和 ReLU 并没有完成学习。

训练还需要数据、标签或其他训练信号、损失函数、反向传播和优化步骤；测试集应与训练数据隔离。模型可能在训练数据上表现很好，却在新设备、光照、语言或业务流程下失效。评估时要按目标场景采样，记录误检、漏检以及人工复核成本。

卷积的共享权重使它对位置变化有结构上的适应性，但不能简单宣称 CNN 对任意平移、旋转和尺度都不变：边界填充、步长、池化和数据分布都会改变实际表现。

## 5. 与 Agent 应用有什么关系

一个能处理截图的 Agent 可能使用视觉模型理解图像，再用工具完成后续任务。CNN 是理解视觉特征的一条重要基础，但现代视觉系统也可能使用视觉 Transformer 或混合架构；不能推断所有多模态 Agent 都由 CNN 构成。

例如，识别一张发票图片中的字段只是一个环节。落地还要检查识别错误、用户是否有权查看该发票、数据是否能送入模型、是否需要人工核对，以及写入财务系统前的审批。模型分数不能替代业务权限。[企业助手本地闭环](../agent/cases/enterprise-agent-local-lab)展示了后续审批和提交的教学链路，但没有图像识别功能。

## 6. 动手练习

1. 手算输入右下角窗口与 $K$ 的互相关，再运行程序核对；交换核的上下两行，观察符号如何变化。
2. 将 `stride` 改为 2，先用公式计算输出尺寸，再检查程序结果；尝试 `padding=1`。
3. 把一个负值替换为正值，观察 ReLU 的变化；解释为什么 ReLU 本身没有训练权重。
4. 设计一个含 3 输入通道、8 输出通道、$5\times5$ 核的无分组卷积层，计算含偏置的参数量，再对照框架文档核验。
