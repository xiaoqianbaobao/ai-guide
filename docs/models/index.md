# 模型与算法

这一部分用于承接从 Python 编程基础到 AI 学习的过渡。

如果你还处在“会一点代码，但还没有进入 AI 学习主线”的阶段，推荐先从 Python 教程开始，再逐步过渡到数据处理、模型基础和工程实践。

## 建议的学习顺序

```text
Python 基础教程
  -> 数据处理工具
  -> 机器学习 / 深度学习 / 大模型基础
  -> 工程与 Agent
```
