# 图神经网络第一课：用消息传递理解节点与关系

企业里的问题往往不只涉及一份文档：一个客户关联多个工单，一张工单关联产品、合同和处理人。如果把这些对象与关系表示为图，能否让模型同时利用对象特征和邻居信息？图神经网络（GNN）提供了一类方法。

本课从三个节点手算一次**消息传递**，再运行不依赖第三方库的 Python。示例只是邻居平均，不训练模型，也不是对真实企业关系图的预测。阅读前建议先理解[向量与矩阵](./linear-algebra-for-agents)和 [CNN 的局部窗口](./cnn-from-pixels-to-features)。

## 1. 图、节点特征和边

图由节点和边组成。节点可以表示客户、工单或文档；边表示某种明确关系，例如“工单属于客户”。边可以有方向和类型，节点与边也可以带属性。

先用一个无向的教学图 $A—B—C$，为每个节点设定二维向量：

| 节点 | 初始特征 | 邻居 |
| --- | --- | --- |
| A | `[1, 0]` | B |
| B | `[0, 1]` | A、C |
| C | `[1, 1]` | B |

数字只是演算用特征，不表示真实客户属性。无向图可视作每条边在两个方向都提供邻居；在有向图中要明确是聚合入邻居、出邻居，还是两者分别处理。

## 2. 手算一轮消息传递

一个常见思路是：每个节点收集邻居消息，聚合后更新自己的表示。我们先采用最简单的规则：**将自身和邻居的向量逐维取平均**，不做可学习变换。

对节点 B，自身与 A、C 的特征之和为 $[0,1]+[1,0]+[1,1]=[2,2]$，除以 3，得到 $[2/3,2/3]$。同理，A 的新表示为 $[0.5,0.5]$，C 为 $[0.5,1]$。

聚合必须基于**本轮开始时**的所有旧向量；若先更新 A，再让 B 使用更新后的 A，结果会依赖节点遍历顺序，那是另一种算法。这里把自节点加入一次：孤立节点没有邻居时，平均值仍是自己的特征。

## 3. 动手运行

在仓库根目录执行：

```bash
cd examples/gnn-basics
python3 message_passing.py
python3 -m unittest -v
```

应看到 A 约 `[0.5, 0.5]`、B 约 `[0.667, 0.667]`、C 约 `[0.5, 1.0]`。测试还覆盖孤立节点、未知邻居、重复边和特征维度不一致。[完整代码](https://github.com/xiaoqianbaobao/ai-guide/tree/main/examples/gnn-basics)的核心是：

```python
sources = [node] + [other for other in neighbors if other != node]
output[node] = [
    sum(features[source][i] for source in sources) / len(sources)
    for i in range(size)
]
```

传入的 `incoming_neighbors` 明确表示**哪些节点向目标节点发送消息**；代码不自动补反向边。示例拒绝重复邻居，因此不支持多重边；真实系统如果边有重复、权重或类型，必须先定义它们的语义，而不是悄悄去重。

## 4. 什么时候它才成为可训练的 GNN？

上面只有平均，并没有学习参数。一个简化的可训练形式可以写成：

$$
h_v^{(l+1)}=\sigma\!\left(W^{(l)}\operatorname{mean}\{h_u^{(l)}:u\in N(v)\cup\{v\}\}+b^{(l)}\right)
$$

其中 $h_v^{(l)}$ 是第 $l$ 层节点 $v$ 的表示，$N(v)$ 是选定方向的邻居，$W$ 和 $b$ 为可学习参数，$\sigma$ 是非线性函数。训练还需要任务目标、损失函数、数据划分和优化器。

这是为了讲清消息传递而写的简化形式，**不等同于**所有 GNN，也不等同于 Kipf 与 Welling 的经典 GCN：后者使用特定的邻接矩阵归一化。不同架构可能改变消息函数、聚合方式、归一化、边特征和采样方式；具体应看模型与实现文档。

## 5. 层数、采样与信息泄露

一轮聚合让节点接收一跳邻居的信息；多轮可扩大影响范围，但层数并不是越多越好。不同问题会受到计算和内存、邻居数量、噪声边及过度平滑等因素影响：过多次聚合可能让节点表示越来越相似，削弱区分能力。需要用目标任务和验证集衡量，而不是盲目增加层数。

评估还要防止信息泄露。例如，在按时间预测未来工单关系时，训练图若已经包含预测时点之后的边，模型就可能使用了未来信息。应明确预测时刻、可见边、特征更新方式，以及训练/验证/测试划分；节点任务、边预测和整图分类的划分方式也不同。

## 6. 与知识图谱和 Agent 的关系

知识图谱通常强调实体、关系类型和可解释的事实组织；GNN 是处理图结构数据的一类模型。两者可以组合，但“存了知识图谱”不等于“训练了 GNN”，GNN 输出也不自动成为经过验证的事实。

如果 Agent 使用客户—工单图检索上下文，必须在**检索、邻居扩展和最终展示**各阶段执行合适的权限控制。不能因为两个节点有边，就认为当前用户有权读取相邻节点；过期关系、推断结果和用户提供的资料也应有来源与版本。业务写入仍需要服务端授权和审批，可参见 [Agent 安全边界](../02-agent-core/agent-security-boundaries)。

## 7. 动手练习

1. 手算节点 A 和 C 的聚合结果；把 B 的特征改为 `[2, 0]` 后重新计算。
2. 给图增加孤立节点 D，解释为什么本例保留它的原特征；尝试传入未知邻居，观察错误。
3. 将 A—B 改成只有 A→B 的有向边，写出每个节点的入邻居；先预测再运行。
4. 设计一个时间切分的工单预测任务，列出预测时点之后绝不应该出现在训练输入中的信息。
