# Python 之后学什么

学完 Python 基础之后，很多人会立刻问一个问题：

“下一步我该去学机器学习，还是先学框架，还是直接做 Agent？”

更稳妥的路径通常不是直接跳到最热的内容，而是先把 Python 能力过渡到“处理真实数据和组织真实代码”的阶段。

## 推荐的下一步顺序

```text
Python 基础
  -> 数据处理基础
  -> 模型与算法基础
  -> 模型调用与脚本封装
  -> AI 工程
  -> Agent 与应用
```

## 第一站：数据处理基础

建议优先进入这些方向：

- `NumPy`
- `Pandas`
- `Matplotlib`
- CSV / JSON / Excel 等常见数据格式处理

原因很简单：

- AI 开发几乎一定会碰到数据
- 你需要先会读取、清洗、统计和转换数据
- 很多模型实验的输入输出，本质上都是结构化数据流

## 第二站：模型与算法基础

在具备基本数据处理能力后，再进入：

- 机器学习基础
- 深度学习基础
- 大模型原理

这时你的学习会更稳，因为你已经能看懂很多示例代码，不会只停留在概念层面。

## 第三站：模型调用与脚本封装

如果你的目标更偏应用开发，可以尽早开始接触：

- HTTP 请求基础
- 调用模型 API
- 结果解析与错误处理
- 配置文件管理
- 日志记录和批处理脚本

这部分会把你从“会写 Python”推进到“能完成最小 AI 工具开发”。

## 第四站：AI 工程与 Agent

当你已经会处理文件、JSON、模块、函数和类之后，再进入：

- 推理服务
- 工程结构设计
- Agent 框架
- 工具调用
- 多步骤任务流程

这时你会明显更容易理解这些内容背后的组织方式。

## 不建议直接跳过的部分

下面这些内容虽然不总是最热门，但非常关键：

- 文件与 JSON 处理
- 字典和列表的熟练使用
- 错误处理
- 模块拆分
- 命令行脚本

如果这些基础薄弱，后续做模型调用和 Agent 开发时会频繁卡在实现细节上。

## 一个更现实的学习目标

如果你想判断自己是否已经从“Python 初学者”进入“AI 开发入门阶段”，可以看下面几件事你是否能独立完成：

- 读取一个 JSON 文件并提取字段
- 批量处理一组文本
- 保存结构化结果
- 为脚本增加异常处理
- 把重复逻辑拆成函数或类
