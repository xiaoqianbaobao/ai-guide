# Python 基础课程说明

<span id="python-基础教程-项目总结"></span>

这是一份早期项目说明。想从头学习 Python，请进入[Python 基础课程](./)，按目录顺序学习环境搭建、数据类型、控制流、面向对象和文件处理。

课程中的代码需要在自己的 Python 环境中运行；具体版本、依赖及运行方式以各篇教程为准。学习时间取决于已有经验和练习投入，不必以固定天数作为完成标准。

如果你已经掌握基础语法，可以继续阅读 [Python 之后学什么](./next-steps)，再根据目标选择数学、模型或 Agent 工程路线。
