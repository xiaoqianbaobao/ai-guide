# Python 基础教程

这是一套面向 AI 学习者设计的 Python 入门课程。

它的目标不是只让你“学会语法”，而是帮你为后续的数据处理、模型调用、实验脚本、服务封装和 Agent 开发打下可继续扩展的基础。

## 这门课适合谁

如果你符合下面任意一种情况，都适合从这里开始：

- 想进入 AI 开发，但 Python 基础还不稳定
- 能看懂少量代码，但写脚本还不熟练
- 学过模型概念，却缺少实际工程编码基础
- 准备继续学习数据处理、机器学习或 Agent

## 学完之后你会得到什么

完成这 5 期内容后，你应该具备以下能力：

- 能独立写出基础 Python 脚本
- 能处理字符串、列表、字典、JSON 和文件
- 能把逻辑拆成函数和模块
- 能理解类与对象的基本组织方式
- 能为后续 AI 项目写最小可运行的数据处理与工具代码

## 为什么这门课会偏向 AI 学习

后续进入 AI 领域时，最常见的工作并不是“从零训练大模型”，而是：

- 清洗文本和结构化数据
- 读取配置、提示词和数据集文件
- 调用模型 API 并处理返回结果
- 组织实验脚本、工具函数和数据处理流程
- 为推理服务和 Agent 应用编写辅助代码

因此，这门课会刻意加强以下基础：

- 文本处理
- 文件与 JSON 处理
- 函数封装
- 模块组织
- 错误处理
- 面向对象的最小工程思维

## 学习地图

```text
环境与语法
  -> 数据类型与容器
  -> 控制流与函数
  -> 面向对象与代码组织
  -> 文件、异常与模块
  -> 数据处理 / 模型调用 / Agent 开发前置基础
```

## 课程结构

### 第1期：Python 环境搭建与基础语法
- Python发展历史与特点
- 环境搭建（Windows/macOS/Linux）
- 第一个Python程序
- 变量与基本数据类型
- 运算符与表达式
- 代码注释与规范

AI 衔接点：

- 为后续运行数据处理脚本和模型调用脚本准备运行环境
- 建立规范的代码书写习惯

### 第2期：数据类型与变量
- 数值类型（int, float, complex）
- 字符串操作与格式化
- 列表、元组、字典、集合
- 类型转换与类型检查
- 常用内置函数

AI 衔接点：

- 处理提示词、标签、样本、配置项和结构化数据
- 学会用合适的数据结构承载输入与输出

### 第3期：控制流与函数
- 条件语句（if-elif-else）
- 循环语句（for, while）
- break与continue语句
- 函数定义与调用
- 参数传递与返回值
- 作用域与命名空间

AI 衔接点：

- 批量处理样本
- 编写规则过滤逻辑
- 把重复的处理过程封装成可复用函数

### 第4期：面向对象编程基础
- 类与对象概念
- 类的定义与实例化
- 属性与方法
- 构造函数与析构函数
- 继承与多态
- 封装性

AI 衔接点：

- 封装模型客户端、配置对象和数据对象
- 为后续理解框架设计与工具抽象做准备

### 第5期：文件操作与异常处理
- 文件读写操作
- 异常处理机制
- 上下文管理器
- 模块与包
- 常用标准库介绍

AI 衔接点：

- 处理 JSON、日志、数据集和提示模板
- 为脚本增加稳定的错误处理与模块化结构

## 建议学习方式

1. **循序渐进**：按照教程顺序学习，不要跳过基础内容
2. **动手实践**：每个概念都要在代码编辑器中亲自运行
3. **理论结合**：理解概念的同时，注重实际应用
4. **及时复习**：定期回顾已学内容，巩固知识点
5. **联系 AI 场景**：思考每一节知识如何服务于数据处理、模型调用或 Agent 开发

## 推荐配套能力

学这门课的同时，可以同步建立这些习惯：

- 学会使用命令行运行脚本
- 习惯把代码拆成函数
- 练习读取和写入 JSON 文件
- 学会看报错并定位问题

## 学完后建议继续学什么

完成本教程后，建议依次进入：

1. `NumPy / Pandas` 等数据处理工具
2. 机器学习基础与常见数据流程
3. 模型 API 调用与服务封装
4. Agent 框架与工程实践
