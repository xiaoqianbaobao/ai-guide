# Agent 产品与 FDE

技术能否在客户现场产生价值，取决于我们是否理解业务、使用者、工作流程和组织约束。本模块从真实类型的业务问题出发，练习发现需求、验证价值、设计人机协作，以及交付可运营的 Agent 系统。

## 推荐阅读

1. [客户访谈实战](./customer-discovery)：从真实行为中寻找值得解决的问题。
2. [从试点到第一个客户](./pilot-to-first-customer)：设计对照、测算价值并讨论合作。
3. [从功能交付到客户成效](./outcome-over-output)：区分功能、用户行为和业务结果，并设计可信的试点。
4. [企业级 Agent 实战路线](../agent/cases/enterprise-agent-roadmap)：查看同一业务场景的技术交付、权限和验收要求。
5. [Agent 线上评估与回归](../06-eval-evolution/production-evaluation-loop)：为实际工作流建立质量、成本和风险的持续评估。

6. [从内容到第一个客户](./content-to-first-customer)：连接公开教程、公众号与真实需求验证。
