# 先修知识

学习 AI 不要求你一开始就会很多，但有些基础越早补齐，后面的理解会越稳定。

## 必备基础

建议至少具备下面三项：

- 基本的计算机使用能力
- 基础中文阅读能力
- 持续动手调试代码的意愿

## 推荐的编程基础

如果你完全没有编程经验，建议先完整学完 [Python 基础教程](/models/python-basics/)。

尤其要掌握这些内容：

- 变量、数据类型、字符串和容器
- 条件语句、循环和函数
- 文件读写和异常处理
- 模块拆分和基础面向对象

这些能力会直接影响你后面写数据处理脚本、清洗数据集、调用模型 API 和组织 Agent 代码。

## 对 AI 学习有帮助的补充基础

即使目前还不会，也建议尽早接触：

- 命令行基础
- Git 和 GitHub 的基本使用
- JSON、CSV 这类常见数据格式
- HTTP API 的基本概念
- 线性代数、概率统计的入门知识

## 不必一开始就精通的内容

下面这些内容很重要，但不需要在起点阶段全部学完：

- 高等数学推导
- 深度学习底层公式细节
- 分布式训练
- 完整的 MLOps 体系
- 复杂的多智能体框架

先建立基础编程和工程直觉，再往上叠加，会更高效。

## 常见误解

- “我先把框架学会，基础以后补”
- “我只需要会调 API，不需要写 Python”
- “我先看最热门的 Agent 内容”

这些路径都容易在后面卡住。AI 开发最终仍然离不开代码组织、数据处理、错误处理和工程调试。

## 建议起点

如果你现在是下面这些状态，可以这样开始：

- 完全零基础：从 Python 课程第一期开始
- 会一点 Python：先读 Python 首页，再查漏补缺
- 会写脚本但没学过 AI：从指南页和模型模块开始
- 会调模型 API：补工程基础，再进入 Agent 模块
