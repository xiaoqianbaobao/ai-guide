# 学习指南

这里不是一篇单独的科普文章，而是整个 `AI Guide` 的学习入口。

如果你希望从编程基础出发，逐步进入数据处理、模型理解、AI 工程实践与 Agent 应用开发，这一页会告诉你应该先学什么、后学什么，以及每个模块的作用。

## 项目定位

`AI Guide` 关注的是“能落地的 AI 学习路径”：

- 先建立 Python 和工程基础
- 再进入数据处理、模型原理和系统实现
- 最后过渡到推理服务、Agent 架构与应用开发

我们的目标不是堆砌热点名词，而是帮助你形成一条可持续推进的学习路线。

## 适合谁学

以下三类读者会最适合从这里开始：

- 想从零搭建 AI 学习路径的自学者
- 已有基础编程能力，准备转向 AI 开发的工程师
- 学过一些模型概念，但缺少系统工程视角的学习者

如果你目前最薄弱的是编程基础，建议优先从 [Python 基础教程](/models/python-basics/) 开始。

## 学习路线

推荐按下面的顺序推进：

| 阶段 | 重点模块 | 你会建立的能力 |
| --- | --- | --- |
| 第 1 阶段 | Python 基础 | 编写脚本、处理文本与文件、组织代码 |
| 第 2 阶段 | 数据与模型基础 | 理解机器学习、深度学习与大模型的基本概念 |
| 第 3 阶段 | AI 工程 | 会做推理调用、服务封装、日志与监控 |
| 第 4 阶段 | Agent | 能理解智能体流程、框架和工程实践 |
| 第 5 阶段 | 应用与资源 | 将知识迁移到真实项目和持续学习中 |

更完整的章节地图见 [学习路线图](./roadmap)。

## 先学什么

如果你还不确定该从哪里开始，可以按下面的判断方式：

- 没写过 Python：先学 [Python 基础教程](/models/python-basics/)
- 会写基础脚本，但不懂 AI：先看 [先修知识](./prerequisites)
- 学过一点机器学习，但没做过项目：先看工程模块和指南页
- 已能调用模型 API：可以开始接触 Agent 与服务架构内容

## 如何使用本站

为了让学习路径更稳定，建议采用“主线学习 + 配套实践”的方式：

1. 先读课程首页，明确本阶段目标
2. 再按顺序学习正文，不要跳过基础章节
3. 每学完一节，自己运行一次示例代码
4. 用小项目或练习把知识固定下来
5. 每完成一个阶段，再进入下一个模块

更具体的使用建议见 [如何使用本知识库](./how-to-learn)。
