# 如何使用本知识库

本站更适合“边读边做”，而不是一口气只看完所有页面。

## 推荐学习方式

建议用下面这个循环：

1. 先读本节目标
2. 再理解核心概念
3. 立刻运行示例代码
4. 改动输入，观察输出变化
5. 完成最小练习
6. 用自己的话复述本节结论

这样做的好处是，你不会停留在“看懂了”，而是能逐步进入“写得出、改得动、能排错”的状态。

## 每个阶段该怎么学

### Python 基础阶段

重点不是背语法，而是建立三种能力：

- 把问题拆成步骤
- 把步骤写成函数或模块
- 把输入、输出和错误处理清楚

### 模型基础阶段

重点不是一次学会所有公式，而是先建立概念地图：

- 数据是什么
- 模型学什么
- 训练和推理有什么区别
- 为什么评估比“跑起来”更重要

### 工程与 Agent 阶段

重点不只是“会调用”，而是能维护：

- 配置从哪里来
- 错误怎么处理
- 日志怎么记录
- 模块怎么拆
- 链路怎么调试

## 推荐的实践方式

每完成一个小节，都建议补一个最小实践：

- 控制流和函数：写一个批量处理脚本
- 面向对象：写一个小型配置或数据对象
- 文件和异常：写一个 JSON/CSV 读取和校验工具
- 模型调用：写一个最小封装层，而不是只在一段脚本里直接写死

## 学习记录建议

建议你保留一个自己的学习目录，至少记录三类内容：

- 示例代码的修改版
- 做错过的问题和修正过程
- 每周一次的总结笔记

如果你未来要做 AI 项目，这些记录会比单纯收藏网页更有价值。

## 如何判断自己真的学会了

可以用下面四个问题自测：

- 我能不能不看原文，自己写出类似示例？
- 我能不能解释为什么这样写？
- 我能不能修改输入后让程序仍然工作？
- 我能不能定位一两个常见错误？

如果四个问题里有两个以上答不上来，说明需要回到代码层再练一轮。

## 给自学者的建议

- 不要求一次学很快，但要保持连续性
- 不要跳过基础章节
- 不要只收藏资料，至少跑一次代码
- 不要把“看过”误认为“掌握”
