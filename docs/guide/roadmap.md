# 学习路线图

这份路线图适合希望系统进入 AI 开发领域的读者。

它的核心原则只有一条：先把“能写、能跑、能组织”的基础打牢，再进入模型、工程与智能体。

## 总体路径

```text
Python 基础
  -> 数据处理与脚本能力
  -> 机器学习与深度学习基础
  -> 大模型与推理调用
  -> AI 工程与服务化
  -> Agent 架构与应用
```

## 第一阶段：Python 基础

目标：

- 读懂和编写基础脚本
- 能处理文本、文件、JSON 和命令行输入
- 学会用函数、模块和类组织代码

这一阶段对应基础编程与脚本能力建设。

它不是一门“通用语法课”而已，而是为后续 AI 学习做准备：

- 第 3 期开始强调批处理、规则判断和函数封装
- 第 4 期会为数据管道、模型封装和配置对象做铺垫
- 第 5 期会进入文件、数据集、配置、异常与模块组织

## 第二阶段：数据与模型基础

目标：

- 理解数据是如何被清洗、表示、训练和评估的
- 知道机器学习、深度学习和大模型分别解决什么问题

建议补齐的方向：

- 机器学习基础
- 深度学习基础
- 大模型原理
- 与 AI 相关的数学基础

如果你已经进入大模型学习，建议把“会调用 API”和“理解模型内部机制”分开看。  
至少要补到下面这一层：

- Transformer 基本结构
- Self-Attention 与 QKV
- 上下文窗口与长文本成本
- Decoder-only LLM 的因果掩码

## 第三阶段：AI 工程

目标：

- 能把模型能力接进真实应用
- 能处理接口调用、日志、配置、错误与性能问题

典型能力包括：

- 请求模型 API
- 组织推理服务
- 处理配置文件与环境变量
- 记录日志、监控异常、进行基本调试

这一阶段也建议开始理解框架原理，而不是只停留在 demo 使用：

- 为什么有的框架用 graph 组织 Agent
- 节点、边、共享状态分别解决什么问题
- Java / Spring 企业系统如何接入模型、RAG、Tool Calling

## 第四阶段：Agent

目标：

- 理解智能体系统的组成部分
- 能区分单轮调用、工作流和智能体
- 能使用框架完成简单任务链路

如果你准备进入更复杂的 Agent 系统，建议继续补齐：

- LangGraph 一类图式编排框架
- Harness 与长任务运行外壳
- Skills、MCP 与工具接入边界
- Eval、Reward 与回归测试

这一阶段不应脱离工程基础。没有 Python、文件处理、模块组织和错误处理能力，Agent 开发通常会停留在“会点平台配置”的层面。

## 第五阶段：应用与长期成长

目标：

- 把所学迁移到真实场景
- 建立持续阅读、复盘和迭代的习惯

建议你在这一阶段开始做：

- 小型自动化脚本
- 数据清洗与分析项目
- 模型调用封装工具
- 多步骤 Agent 应用原型

## 推荐节奏

如果你是自学者，可以参考这个节奏：

- 每周学习 2 到 3 个章节
- 每周至少跑通 1 个示例程序
- 每完成一个模块，做 1 个小练习项目
- 每月回顾一次“自己已经能独立完成什么”

## 常见误区

- 一开始就直接上 Agent 框架，忽略 Python 基础
- 只看概念，不运行代码
- 只学模型名词，不学数据与工程
- 过早追逐新工具，却没有建立稳定的学习主线
